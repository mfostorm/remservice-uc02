# Руководство пользователя ИС «РемСервис»

## 1. Запуск и авторизация

1. Запустите `RemService.exe` (или нажмите **F5** в Visual Studio).
2. В форме авторизации введите логин, пароль и выберите роль.
3. Демонстрационные учётные записи:

| Логин | Пароль | Роль | Доступные разделы |
|-------|--------|------|-------------------|
| priemshik1 | 12345 | Приёмщик | заказ-наряды, диагностика, просмотр склада |
| admin | admin | Администратор | все разделы, включая администрирование |

## 2. Главная форма (рабочее место)

Верхняя панель содержит пять показателей: заказ-нарядов в работе, ожидают согласования,
готовы к выдаче, просрочено по сроку, выручка за месяц.
Ниже расположен реестр заказ-нарядов с цветовой индикацией статусов.

Кнопки перехода: **Новый заказ-наряд**, **Диагностика и ремонт**, **Склад запчастей**,
**Отчёты и аналитика**, **Администрирование**. Доступность кнопок определяется ролью
пользователя.

## 3. Приём техники

Заполните три группы полей — «Клиент», «Техника», «Неисправность и сроки» — и нажмите
**Сохранить заказ-наряд**. Кнопка **Печать квитанции** формирует документ для клиента,
**Отправить на диагностику** переводит заказ в статус «Диагностика».

## 4. Диагностика и калькуляция

Укажите инженера, дату, выявленную неисправность и заключение. Таблицы «Работы»
и «Запасные части» формируют смету; итог пересчитывается автоматически с учётом скидки
клиента. Кнопка **Согласовать** фиксирует согласие клиента, **Отказ клиента** закрывает
заказ-наряд.

## 5. Склад запасных частей (режим администратора)

Доступны операции **INSERT**, **UPDATE**, **DELETE** над таблицей `Parts`.
Позиции с остатком ниже неснижаемой нормы выделяются жёлтым, отсутствующие — красным.
Кнопка **Заказ поставщику** формирует заявку по дефицитным позициям.

## 6. Администрирование

Форма содержит список пользователей, матрицу прав выбранной роли и журнал аудита.
Доступны добавление, изменение, сброс пароля и блокировка учётных записей.

## 7. Отчёты и аналитика

Выберите период и вид отчёта, нажмите **Сформировать**. Отображаются ключевые показатели,
диаграмма по видам техники, таблица загрузки мастеров и автоматические выводы системы.
Экспорт — в PDF и Excel.

## 8. Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| F5 | обновить данные |
| Ctrl+N | новый заказ-наряд |
| Ctrl+P | печать квитанции |
| Esc | закрыть текущую форму |
