# РемСервис — информационная система сервисного центра по ремонту техники

Учебная практика **УП.02**, вариант **20** — «Автоматизация работы сервисного центра по ремонту техники».

Репозиторий содержит полный комплект проектной документации и программную реализацию
графического интерфейса информационной системы **«РемСервис»**.

---

## Назначение системы

ИС «РемСервис» автоматизирует сквозной процесс обслуживания клиента сервисного центра:

| Этап | Содержание |
|------|------------|
| Приём техники | регистрация клиента и изделия, внешний осмотр, оформление заказ-наряда, печать квитанции |
| Диагностика | назначение инженера, техническая диагностика, дефектная ведомость, расчёт стоимости |
| Согласование | уведомление клиента, фиксация согласия или мотивированного отказа |
| Ремонт | подбор и списание запасных частей, выполнение работ по технологическим картам |
| Контроль качества | приёмо-сдаточные испытания, акт приёмки, возврат на доработку при браке |
| Выдача и учёт | выдача техники, приём оплаты, гарантия, аналитическая отчётность |

## Состав ветки case_task1 — моделирование бизнес-процессов

* контекстная диаграмма IDEF0 **A-0** и декомпозиции **A0**, **A1–A5**, **A3.2** (три уровня);
* диаграмма **IDEF3** «Обработка заказа на ремонт техники» с узлами XOR и AND;
* контекстная диаграмма и диаграмма первого уровня **DFD** (нотация Гейна — Сарсона);
* восемь диаграмм **UML**: вариантов использования, деятельности, состояний,
  последовательностей, классов, компонентов, развёртывания, пакетов.

## Состав ветки case_task3 — графический интерфейс

Проект **Microsoft Visual Studio 2022**, язык **C++/CLI**, каркас **Windows Forms**,
целевая платформа **.NET Framework 4.8**.

```
src/
  RemService.sln
  RemService/
    RemService.vcxproj
    RemService.cpp        — точка входа
    LoginForm.h           — авторизация и выбор роли
    MainForm.h            — рабочее место: KPI и реестр заказ-нарядов
    OrderForm.h           — приём техники и оформление заказ-наряда
    DiagnosticForm.h      — диагностика и калькуляция ремонта
    WarehouseForm.h       — склад запчастей (работа с БД: INSERT/UPDATE/DELETE)
    AdminForm.h           — пользователи, роли, права, журнал аудита
    ReportForm.h          — отчёты и аналитика
source/
  RemServiceDB.sql        — создание и наполнение базы данных
```

### Сборка и запуск

1. Установить Visual Studio 2022 с рабочей нагрузкой **«Разработка классических приложений на C++»**
   и отдельным компонентом **«Поддержка C++/CLI для v143»**.
2. Открыть `src/RemService.sln`.
3. Выбрать конфигурацию `Debug | x64` и нажать **F5**.
4. Демонстрационный вход: логин `priemshik1`, пароль `12345`
   (либо `admin` / `admin` — полный доступ).

### Развёртывание базы данных

```sql
-- SQL Server Management Studio → New Query → открыть файл
:r source\RemServiceDB.sql
```
